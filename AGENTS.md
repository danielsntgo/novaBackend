
# Reglas del backend

- Al terminar cada fase del proyecto, actualiza `docs/openapi.json` y `docs/contrato-api.md` para que coincidan con el código real vigente. Regenera el OpenAPI desde la API cuando esté disponible; describe solo el comportamiento implementado y marca como pendiente lo que aún no exista.
- No cambies el código de la aplicación solo para hacer coincidir la documentación, salvo que el usuario lo solicite expresamente.
